Oregon Jurisdiction Review

Oregon is a provisional H-EDU jurisdiction, not yet a live deployment.

H-EDU is validating Oregon as a possible Type 4 state by testing whether secure district reporting through SAR and AWE can support a clean ELPA Speaking versus ELPA Writing extraction path, supported by Oregon's existing statewide assessment and accountability environment.

Provisional

Current Judgment

Oregon is structurally strong, but the secure extract path still controls the build.

What Oregon Is

A serious expansion target with statewide academic, EL, secure-reporting, and accountability systems already in place.

Best H-EDU Path

The strongest Oregon model is a direct ELPA Speaking versus ELPA Writing oral-written comparison at district level.

What Still Controls The Build

The gating issue is whether Oregon district or state users can supply the needed SAR or AWE artifact in a clean reusable district format.

Measurement Architecture

Oregon already has the right systems. The extract artifact is the open question.

Oregon is promising because it combines OSAS, ELPA, SAR, AWE, ARUA, CRS, and official district accountability reporting inside one coherent state environment. That makes Oregon stronger than states that require immediate cross-system improvisation.

Academic System

OSAS ELA provides the statewide academic assessment structure and public district reporting context.

EL System

ELPA is the clearest H-EDU oral-written pathway because it already contains speaking and writing domains inside one statewide EL assessment system.

Accountability Layer

At-A-Glance Profiles and Accountability Detail Sheets give Oregon strong interpretation context once the district extract path is confirmed.

Likely Access Path

The strongest likely reporting path is SAR and AWE, supported by ARUA and CRS for score review and validation.

Build Decision

Oregon is ready for research and provisional website placement, but not yet for a live H-EDU build. The right next step is to confirm whether Oregon district or state users can access an existing SAR report, AWE extract, or related file that shows ELPA Speaking and ELPA Writing side by side for the same year.

  • If that file exists, Oregon becomes a serious Type 4 candidate.
  • If it does not, Oregon shifts toward a mixed-model or partner-access build path.
  • Until that point, Oregon should remain explicitly provisional.

Next Step

Oregon needs one practical secure-reporting test before any live deployment.

H-EDU's next Oregon task is to confirm whether SAR, AWE, ARUA, CRS, or an Oregon district partner can provide district-level ELPA Speaking and ELPA Writing reporting in a clean buildable format.
