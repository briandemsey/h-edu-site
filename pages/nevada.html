Nevada Jurisdiction Review

Nevada is a provisional H-EDU jurisdiction with a confirmed district-report ACCESS domain path.

H-EDU has already confirmed one real Nevada data path through WIDA AMS district reporting. The remaining question is whether the richer posted ACCESS data files support a stronger ACCESS Speaking versus ACCESS Writing build.

Provisional

Current Judgment

Nevada is structurally strong, but verification still controls the build.

What Nevada Is

A serious expansion target with statewide academic, EL, accountability, and longitudinal-data systems already in place, plus one confirmed district ACCESS report path.

Best H-EDU Path

The strongest Nevada model is a direct ACCESS Speaking versus ACCESS Writing oral-written comparison, ideally from the richer WIDA AMS data files and at minimum from the confirmed district report path.

What Still Controls The Build

The gating issue is no longer whether Nevada has a data path. It is whether Nevada district or state users can supply the richer WIDA AMS data-file artifact in a clean reusable district format.

Measurement Architecture

Nevada already has the right systems. The reporting path is the open question.

Nevada is promising because it combines a confirmed WIDA AMS district report path, likely richer posted ACCESS data files, SBAC, ACT, the Nevada Accountability Portal, Nevada Report Card, NV SLDS, and SAIN inside one coherent state reporting environment. That makes Nevada a stronger candidate than states that require immediate cross-system improvisation.

Academic System

SBAC provides the main statewide academic assessment structure and public district reporting context, with ACT adding a separate college-readiness layer.

EL System

ACCESS for ELLs is the clearest H-EDU oral-written pathway because it already contains speaking and writing domains inside one EL assessment system.

Accountability Layer

Nevada Accountability Portal and Nevada Report Card give Nevada strong interpretation and accountability context once the extract path is confirmed.

Likely Access Path

Nevada already has one confirmed district-report path through WIDA AMS. The strongest likely richer path is the posted ACCESS data file set, supported by NV SLDS and SAIN.

Build Decision

Nevada is already strong enough for confident provisional placement. The right next step is to confirm whether Nevada district or state users can access an existing posted WIDA AMS data file or related export that shows ACCESS Speaking and ACCESS Writing side by side for the same year.

  • If that file exists, Nevada becomes a near-ready Type 4 candidate.
  • If it does not, Nevada shifts toward a mixed-model, public-records, or data-request build path.
  • Until that point, Nevada should remain explicitly provisional.

Next Step

Nevada needs one practical access test before any live deployment.

H-EDU's next Nevada task is to confirm whether the richer posted WIDA AMS data files can provide ACCESS Speaking and ACCESS Writing reporting in a clean buildable format.
