Texas Jurisdiction Review

Texas is a provisional H-EDU jurisdiction, not yet a live deployment.

H-EDU is validating Texas as a possible Type 4 state by testing whether TEA public reporting supports clean district-level extraction of TELPAS speaking and writing values, joined statewide by county-district number.

Measurement Architecture

The Texas structure is already clear. The public data path is not.

Texas is unusually promising because TELPAS already measures listening, speaking, reading, and writing inside one statewide EL proficiency system. That gives H-EDU a plausible direct oral-written path without forcing a weak crosswalk first.

Build Judgment

Current H-EDU judgment

Texas is structurally promising, strategically important, and ready for website placement as a provisional jurisdiction. It is not yet ready to be described as live or confirmed Type 4.

  • Go for continued jurisdiction research and provisional website placement.
  • No-Go for app build until the district-level speaking-writing extraction path is proven.
  • If the public file exists, Texas becomes a serious Type 4 candidate.
  • If it does not, Texas shifts toward a mixed-model or accountability-monitoring classification.

Next Step

The next step is not deployment. It is extraction proof.

H-EDU's next Texas task is one practical extraction test against official TEA public reporting surfaces to determine whether district-level TELPAS Speaking and TELPAS Writing can be pulled statewide in a clean, buildable format.
