Pennsylvania Jurisdiction Review

Pennsylvania ranks last in the nation in Hispanic-white opportunity gaps.

H-EDU is validating Pennsylvania as a Type 4 jurisdiction by confirming whether PDE public reporting supports district-level extraction of ACCESS Speaking and Writing values, joined statewide by AUN.

Provisional

Decision Status

Pennsylvania is a COSSBA Phase 1 priority with the worst equity rankings in America.

What Pennsylvania Is

A Phase 1 COSSBA priority jurisdiction under active review for H-EDU expansion. WIDA member since 2007. ~100,000 English Learners across 500 districts.

Best-Case Path

A true Type 4 build using ACCESS Speaking versus ACCESS Writing at district grain, joined statewide by AUN (Administrative Unit Number).

Current Constraint

Domain-level ACCESS data exists in PA's secure systems (eMetric, WIDA AMS) but is not publicly downloadable. A formal RTKL request to PDE is required.

Why Pennsylvania

The strongest equity case of any U.S. state.

50th
Hispanic-White Gap

Dead last in the nation. No state has a wider Hispanic-white education opportunity gap than Pennsylvania.

49th
Black-White Gap

Second to last nationally. 25+ point gaps persist between White and Black students with no measurable improvement since 2003.

49th
Income Gap

Second to last in the low-income vs high-income opportunity gap. Structural inequities compounded by historic underfunding.

Measurement Architecture

The PA infrastructure is mature. The public data path is not.

Pennsylvania administers WIDA ACCESS with four separately scored domains. The assessment infrastructure supports Type 4 detection. The constraint is public data access, not measurement capability.

Academic System

PSSA (Grades 3-8) and Keystone Exams (Algebra I, Biology, Literature) are the statewide academic assessment surfaces.

EL System

WIDA ACCESS measures Listening, Speaking, Reading, and Writing as four separate domain scores (100-600 scale).

Data Backbone

PIMS (PA Information Management System) is the statewide SLDS. PVAAS provides growth analytics.

Join Key

AUN (Administrative Unit Number) is the 9-digit district identifier used across all PDE systems.

Build Judgment

Current H-EDU judgment

Pennsylvania is structurally promising, strategically essential (COSSBA Phase 1), and has the worst equity rankings in the nation — making the VERA oral-written delta analysis both technically feasible and politically compelling.

  • Go for RTKL data request to PDE for aggregate domain-level ACCESS data by AUN.
  • Go for provisional website placement and continued research.
  • Go for district artifact requests (Philadelphia, Reading, Allentown).
  • No-Go for app build until district-level Speaking + Writing extraction is confirmed.
  • If the RTKL request succeeds, Pennsylvania becomes a confirmed Type 4 jurisdiction.
  • If it does not, Pennsylvania shifts toward a mixed-model or accountability-monitoring classification.

Next Step

The formal Right-to-Know Law request has been drafted.

H-EDU is preparing a targeted RTKL request to PDE for aggregate ACCESS domain-level proficiency distributions by district, to determine whether Pennsylvania can support a clean, buildable oral-written delta analysis.
