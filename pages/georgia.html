Georgia Jurisdiction Review

Georgia is a provisional H-EDU jurisdiction with a confirmed district-report ACCESS domain path.

H-EDU has already confirmed one real Georgia data path through WIDA AMS district reporting. The remaining question is whether the richer posted ACCESS data files support a stronger ACCESS Speaking versus ACCESS Writing build.

Provisional

Current Judgment

Georgia is structurally strong, but verification still controls the build.

What Georgia Is

A serious expansion target with statewide academic, EL, accountability, and longitudinal-data systems already in place, plus one confirmed district ACCESS report path.

Best H-EDU Path

The strongest Georgia model is a direct ACCESS Speaking versus ACCESS Writing oral-written comparison, ideally from the richer WIDA AMS data files and at minimum from the confirmed district report path.

What Still Controls The Build

The gating issue is no longer whether Georgia has a data path. It is whether Georgia district users can supply the richer WIDA AMS data-file artifact in a clean, reusable district/system format.

Measurement Architecture

Georgia already has the right systems. The reporting path is the open question.

Georgia is promising because it combines a confirmed WIDA AMS district report path, likely richer posted ACCESS data files, Georgia Milestones, CCRPI, GSGM, and SLDS inside one coherent state reporting environment. That makes Georgia a stronger candidate than states that require immediate cross-system improvisation.

Academic System

Georgia Milestones provides the statewide academic assessment structure and public district/system reporting context.

EL System

ACCESS for ELLs is the clearest H-EDU oral-written pathway because it already contains speaking and writing domains inside one EL assessment system.

Accountability Layer

CCRPI and GSGM give Georgia strong interpretation and accountability context once the extract path is confirmed.

Likely Access Path

Georgia already has one confirmed district-report path through WIDA AMS. The strongest likely richer path is the posted ACCESS data file set, supported by SLDS and MyGaDOE Portal.

Build Decision

Georgia is already strong enough for confident provisional placement. The right next step is to confirm whether Georgia district or system users can access an existing posted WIDA AMS data file or related export that shows ACCESS Speaking and ACCESS Writing side by side for the same year.

  • If that file exists, Georgia becomes a near-ready Type 4 candidate.
  • If it does not, Georgia shifts toward a mixed-model or partner-access build path.
  • Until that point, Georgia should remain explicitly provisional.

Next Step

Georgia needs one practical access test before any live deployment.

H-EDU's next Georgia task is to confirm whether the richer posted WIDA AMS data files can provide ACCESS Speaking and ACCESS Writing reporting in a clean buildable format.
